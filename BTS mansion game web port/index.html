About

Browser port of a large-scale text-based horror adventure originally built in C++ by a team of seven engineers over three months.

Development

The original game used a custom console engine with room navigation, inventory, sanity pressure, and self-contained puzzle modules. This web version rebuilds that experience as a terminal-style interface in the browser. The C++ project remains the source of truth for gameplay content.

Web port status: Phase 7a — Mirror puzzle live. Gallery / fountain / maze solvers still stubbed.
