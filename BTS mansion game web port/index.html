About

Browser port of a large-scale text-based horror adventure. Originally built in C++ in 2024, ported to web in 2026.

Development

The original "BTS Mansion" game used a custom console engine with room navigation, inventory, puzzle systems, and many more proprietary mechanics. This web version was built by Brent Mercado, and rebuilds that experience as a terminal-style interface in the browser. The C++ project remains the source of truth for gameplay content. This game was developed in three months, from conception to final deployment, by a team of seven engineers! We hope you enjoy it!
